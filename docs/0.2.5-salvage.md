# 0.2.5 Salvage Inventory

Snapshot of the pre-rebuild codebase, taken before gutting Scryer for the
grouping/conformance rebuild. Use this to decide what to re-implement and where
to find the original.

## Reference copy

The full 0.2.5 tree is preserved two ways:

- **Tag** `v0.2.5` (and `main`) — permanent, immutable. `git show v0.2.5:<path>`.
- **Worktree** `../scryer-legacy` — the entire 0.2.5 codebase as a live sibling
  directory, browsable/greppable with normal tools. Remove later with
  `git worktree remove ../scryer-legacy`.

Nothing below needs copying anywhere — it is already retrievable from both.

## Dispositions

- **KEEP** — survives largely as-is.
- **REWRITE** — concept/logic survives; code rebuilt for the new model.
- **SHELVE** — a real later layer, not layer 1; reintroduce from `v0.2.5`.
- **DROP** — tied to the box-and-line graph abstraction being abandoned; not returning.

## Summary

- **DROP** is concentrated and large: the entire ReactFlow canvas, edge
  geometry, node renderers, shapes, and `planar.ts` — roughly half the frontend
  LOC, `planar.ts` alone 1788 lines. Abandoning box-and-line removes a lot.
- **KEEP** outright: the `ui/` design system, theme system, `xtask`, the
  codebase scanner, generic shell bits.
- **REWRITE** is the real work: shell, storage/watcher, groups logic, the MCP
  tool set, `scryer-core` types and I/O.
- **SHELVE** (reintroduce as later layers): flows, the advisor, drift/conformance.
